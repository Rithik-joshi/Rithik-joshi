### 🌍 JourneyCraft — Smart Travel Itinerary Generator

A responsive travel planning application that helps users create personalized travel itineraries based on their destination, budget, travel dates, and preferences.

**Key Features:**
- 🗺️ Personalized day-by-day travel itineraries
- 💰 Estimated trip budget planning
- 🤖 Optional AI-powered itinerary generation
- 🌙 Responsive interface with dark mode
- 💾 Save and view travel itineraries
- ⚡ React frontend with Express backend
